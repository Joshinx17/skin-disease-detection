# skin-disease-detection
This project helps to identify the 7 types of skin diseases :
1. Melanoma (mel) → very dangerous cancer ⚠️
2. Basal Cell Carcinoma (bcc) → skin cancer
3. Actinic Keratosis (akiec) → pre-cancer
4. Melanocytic Nevi (nv) → normal moles
5. Benign Keratosis (bkl) → harmless
6. Dermatofibroma (df) → harmless
7. Vascular lesions (vasc) → blood-related spots
