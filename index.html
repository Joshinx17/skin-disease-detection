The Challenge

Why Automated
Diagnosis Matters

Skin diseases affect millions globally. Melanoma — the deadliest form of skin cancer — has dramatically better survival rates when caught early. Yet traditional diagnosis depends on scarce expert dermatologists, is subjective, and inaccessible in rural regions.

🌍
Global Dermatologist Shortage
Rural and underserved regions lack access to qualified skin specialists, delaying critical diagnoses and worsening patient outcomes.
👁️
High Visual Similarity
Benign and malignant lesions can appear virtually identical to the human eye — melanoma vs. nevi being the most dangerous confusion.
⚖️
Severe Class Imbalance
The HAM10000 dataset reflects real-world distributions where benign cases vastly outnumber malignant ones, making ML training challenging.

Preprocessing · Step 02
Image Normalization Formula
All dermoscopic images are resized to 224×224 pixels for ResNet50 compatibility. Pixel intensities are normalized using min-max normalization to stabilize gradient updates and accelerate training convergence.
# Min-max normalization x_norm = (x − x_min) / (x_max − x_min) # ImageNet-standard channel normalization mean = [0.485, 0.456, 0.406] std = [0.229, 0.224, 0.225] transform = Compose([ Resize((224, 224)), ToTensor(), Normalize(mean, std) ])
Training · Optimization
Loss Function & Optimizer
Categorical cross-entropy loss penalizes incorrect predictions while the Adam optimizer adaptively adjusts learning rates based on first- and second-order gradient statistics, enabling stable convergence across all 7 disease classes.
# Cross-entropy loss (N samples, 7 classes) ℒ = −Σᵢ Σ꜀ yᵢ꜀ · log(ŷᵢ꜀) # Adam optimizer optimizer = Adam( model.parameters(), lr=1e-4, # initial LR betas=(0.9, 0.999), # momentum terms eps=1e-8 ) criterion = CrossEntropyLoss()
Feature Extraction · Step 03
Transfer Learning Strategy
ResNet50 pretrained on ImageNet provides a powerful visual backbone. The final FC layer is replaced with an Identity mapping to extract the raw 2048-dimensional feature embedding, which captures lesion texture, shape, colour, and boundary patterns.
# CNN feature extraction fᵢ = Φ(xᵢ; θ) # Φ = ResNet50 backbone, θ = pretrained weights class FusionModel(nn.Module): def __init__(self): self.cnn = resnet50(pretrained=True) self.cnn.fc = nn.Identity() # → 2048-d self.meta_net = nn.Sequential(...) self.classifier = nn.Sequential(...)
Fusion · Step 04
Metadata Encoding & Fusion
Patient metadata (age, biological sex, lesion localization) is encoded into a 19-dimensional vector and passed through a 3-layer MLP to produce an 8-dimensional clinical embedding, then concatenated with the visual feature for a 2056-dim fused vector.
# Metadata: 19 features → 16 → 8 dims meta_net = Sequential( Linear(19, 16), BatchNorm1d(16), ReLU(), Dropout(0.3), Linear(16, 8), ReLU() ) # Fusion: concat [2048 + 8] = 2056-d fused = cat([img_feat, meta_feat], dim=1)

Training Dynamics (14 Epochs)

Grad-CAM (Gradient-weighted Class Activation Mapping) generates visual explanations by computing gradient flow through the final convolutional layer — revealing exactly which lesion regions drove the model's prediction.

1
Forward Pass
The dermoscopic image passes through all ResNet50 layers, producing feature maps at layer4 with rich visual representations.
2
Gradient Computation
A one-hot vector for the predicted class is backpropagated. The gradients flowing into layer4 indicate which feature map channels matter most.
3
Weighted Activation Map
Channel-wise weights are computed by global average pooling the gradients. These weights are applied to the activation maps and summed.
4
ReLU & Upsampling
ReLU removes negative contributions (regions that reduce class confidence). The map is upsampled to 224×224 and overlaid on the original image.
5
Clinical Transparency
Clinicians can verify the AI is looking at the actual lesion, not background skin or image artifacts — building justified trust in the prediction.
Grad-CAM Formula
LcGrad-CAM = ReLU(Σk αck · Ak)
where αck = (1/Z) Σᵢ Σⱼ (∂yc/∂Akij) is the importance weight for activation map Ak

Clinical Significance

Real-World
Impact & Future

Beyond accuracy numbers — the framework addresses genuine clinical needs, with implications for early screening, telemedicine, and healthcare equity in resource-limited settings across the developing world.

🏥
Early Detection Support
The model's 99% melanoma recall means only ~1% of melanoma cases are missed. In real-world screening, this represents hundreds of lives saved annually through early intervention when treatment success rates are highest.
🌍
Healthcare Equity
Rural and underdeveloped regions with limited specialist access can deploy this system as a first-line triage tool. A smartphone with the deployed model can match the diagnostic sensitivity of expert dermatologists for malignant lesions.
🔒
Clinically Safe Errors
Error analysis reveals the model preferentially makes false-positive errors (benign misclassified as malignant) rather than false negatives. This "cautious" pattern aligns with clinical priorities — over-referral is safer than missed cancer.
Limitations & Future Work

Known Limitations &
Planned Extensions

Skin Tone Diversity HAM10000 underrepresents darker skin tones. Future work includes StyleGAN3-based synthetic augmentation for diverse populations.
Melanoma False Positives Precision of 0.56 for melanoma means over-referral. Future calibration using Platt scaling or temperature scaling will improve specificity.
Mobile Deployment Transformer attention increases computational cost. Future work: knowledge distillation to create a lightweight MobileNet-based variant.
External Validation Testing on ISIC 2020, PH2, and Derm7pt datasets will confirm generalization beyond HAM10000's specific clinical distribution.
Real-Time Web & Mobile App The Streamlit proof-of-concept will be extended into a production-grade application with HIPAA-compliant data handling.
CNN–Transformer Ensemble Exploring hybrid ViT + ResNet ensembles and attention-based fusion mechanisms to further boost minority class performance.
